# DotnetTemplates

[![NuGet](https://img.shields.io/nuget/dt/pandatheque.templates.svg)](https://www.nuget.org/packages/pandatheque.templates) 
[![NuGet](https://img.shields.io/nuget/vpre/pandatheque.templates.svg)](https://www.nuget.org/packages/pandatheque.templates)

Buch of templates based on the dotnet new command.

### Installing Templates

You should install [Templates with NuGet](https://www.nuget.org/packages/pandatheque.templates) using the .NET command line interface:

    dotnet new install Pandatheque.Templates
